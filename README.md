# 🚗 Car Sales Dashboard | Power BI

## 📌 Project Overview
The **Car Sales Dashboard** is an interactive data visualization project developed using Microsoft Power BI to analyze car sales performance, revenue, pricing, and customer preferences. It provides meaningful insights into sales trends and vehicle performance through dynamic charts, KPIs, and interactive filters.

## 🎯 Objectives
- Analyze overall car sales performance.
- Track total sales, revenue, and average car prices.
- Identify popular car brands, models, and vehicle types.
- Compare sales across different categories and time periods.
- Provide actionable insights through interactive dashboards.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization
- **Microsoft Excel** – Dataset preparation and data cleaning
- **Power Query** – Data transformation and preprocessing
- **DAX (Data Analysis Expressions)** – Measures and calculations

## 📊 Key Features
- **KPI Cards:** Display important sales metrics.
- **Interactive Visualizations:** Charts and graphs for exploring sales trends.
- **Brand & Model Analysis:** Compare vehicle performance across brands and models.
- **Slicers & Filters:** Filter data by available categories, such as brand, vehicle type, and time period.
- **Dashboard Navigation:** Navigate between dashboard pages using buttons.
- **Dynamic Analysis:** Visuals update automatically based on selected filters.
- **Power BI Q&A:** Explore supported business questions using natural language.

## 📈 Key Insights
The dashboard helps users:
- Understand overall sales and revenue performance.
- Identify top-performing car brands and models.
- Compare average vehicle prices.
- Discover sales patterns across categories and periods.
- Make data-driven business decisions.

*Note: Actual insights depend on the dataset and the results displayed in the dashboard.*

## ⚙️ Project Workflow
1. Collected and imported car sales data from Excel.
2. Cleaned and transformed the dataset using Power Query.
3. Created calculated measures using DAX.
4. Designed KPI cards, charts, tables, and other visuals.
5. Added slicers, filters, and navigation buttons.
6. Tested dashboard interactivity and validated the displayed results.

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` dashboard file.
4. If prompted, update the data source path to the Excel dataset.
5. Refresh the data if required.
6. Explore the dashboard using slicers, filters, charts, and navigation buttons.
